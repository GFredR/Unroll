# Security Policy / 安全策略

**中文**

开卷解析不可信的归档文件(可能来自任何来源),我们认真对待解析层的安全问题。

- **请勿公开提交安全漏洞**:使用 GitHub 的 [Private vulnerability reporting](https://github.com/GFredR/Unroll/security/advisories/new) 私密报告。
- 报告时请附:开卷版本、macOS 版本、能触发问题的归档文件特征(格式 / 结构 / 加密方式)。**不要直接附恶意样本文件**。
- 纯看图器承诺:App 自身零网络请求,不采集任何数据;崩溃上报仅在异常退出后、经你确认才打开预填的 issue 页面。

**English**

Unroll parses untrusted archive files that may come from anywhere — parser security is taken seriously.

- **Please do not open public issues for security vulnerabilities.** Use GitHub [Private vulnerability reporting](https://github.com/GFredR/Unroll/security/advisories/new).
- Include: Unroll version, macOS version, and the characteristics of the triggering archive (format / structure / encryption). **Do not attach malicious samples.**
- Promise of a pure viewer: the app itself makes zero network requests and collects nothing; crash reporting only opens a prefilled issue page after an abnormal exit, and only with your confirmation.
